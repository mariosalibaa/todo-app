# Todo App

Team task management application built with Node.js.

## Features
- Create, update, and delete tasks
- Organize tasks by project, department, and company
- Set priorities and track status
- Multi-user support

## Development

```bash
npm install
npm start
```

The app runs on `http://localhost:8081` by default.

## Deployment

This app is deployed on Render. Push to the `main` branch to trigger automatic deployment.

## Tech Stack
- Node.js (server)
- HTML/CSS/JavaScript (frontend)
- JSON (data storage)
