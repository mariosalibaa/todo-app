Facts

  • The ✦ Ask button has been on every hub page since 26 Sep 2026. It runs Claude Sonnet 5 on the server, and the key stays on Vercel.
  • Workers and partners keep the read-only tools: ledgers, balances and line search, limited to their own ledger.

How the dev queue works

  • When a request needs code, the assistant writes a brief and saves it at /dev. On that page Mario can edit, mark done, drop, or "Copy prompt" (all open requests in one brief).
  • On the laptop: in VS Code, say /hub-dev-queue. Claude Code runs node dev-queue.mjs, does each request, verifies, deploys, and then runs --done <id> --commit <hash>.
